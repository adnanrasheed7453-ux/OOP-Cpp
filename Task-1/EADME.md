# OOP Lab - Task 1

This folder contains a collection of C++ programs developed as part of the Object-Oriented Programming (OOP) Lab coursework.

The programs focus on understanding and implementing fundamental OOP and C++ concepts through practical examples. They demonstrate how classes, objects, constructors, structures, arrays, and functions can be used to organize and manage data efficiently.

### Concepts Covered

* Default Constructor
* Parameterized Constructor
* Classes and Objects
* Structures and their Members
* Arrays of Structures
* Functions with Structures
* Object Creation and Data Handling
* Basic C++ Programming Concepts

### Programs Included

The task includes multiple C++ programs based on different practical scenarios, such as student data, movie information, product prices, circle area calculation, and bank account balance management.

These programs were created to strengthen programming fundamentals and develop a better understanding of Object-Oriented Programming concepts in C++.
