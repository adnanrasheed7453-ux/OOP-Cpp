# OOP Lab - Task 1

This folder contains the C++ programs completed for OOP Lab Task 1.

The programs cover basic Object-Oriented Programming concepts, including:

* Default and Parameterized Constructors
* Structures and their members
* Arrays of Structures
* Functions with Structures
* Object creation and data handling
* Basic C++ programming concepts

These programs were developed as part of the OOP Lab coursework.
